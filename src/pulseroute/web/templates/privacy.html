Privacy Policy & KVKK / GDPR Notice

LAST REVIEWED FOR THIS CODEBASE • 2026-08-22

1. Scope & Data Controller

PulseRoute is self-hosted, open-source software (MIT License). This notice describes how the PulseRoute application itself handles data at the code level; the operator running this specific instance — reachable at {{ operator_contact_email or 'the address listed by the site operator, if any' }} — is the data controller for any personal data processed here, not the PulseRoute project.

2. Account Data & Passwords

Registering an account stores your e-mail address, optional display name, and a password hash. Passwords are hashed with bcrypt (one-way, salted) before storage — the plaintext password is never written to disk and cannot be recovered or "decrypted" by anyone, including the operator; a forgotten password can only be reset, not retrieved.

3. Workspace & Link Data Isolation

Every account gets its own workspace on signup; there is no shared workspace between users. Links, click analytics, and custom domains are only visible to, and only manageable by, members of the workspace that owns them — every relevant API endpoint verifies workspace membership before returning or changing data. Links created without an account are not attached to any workspace, expire automatically after 24 hours, and cannot be edited or deleted by anyone (including the person who created them) through the API.

4. IP Address Anonymization & Cookieless Tracking

Raw visitor IP addresses are never committed to permanent storage. Incoming addresses are masked before persistence by truncating the final octet (IPv4 /24) or the trailing bits (IPv6 /48). Click telemetry (device, browser, referrer, approximate geography) is derived from standard HTTP headers and the masked IP only — no tracking cookies are set by the redirect engine.

5. Application-Level Security Measures

  • SQL injection: all database access goes through a parameterized async ORM (SQLAlchemy) — no raw string-built SQL.
  • Brute-force protection: repeated failed logins from the same IP trigger a 15-minute lockout after 5 attempts.
  • Abusive traffic / basic DDoS mitigation: link creation and other write endpoints are rate-limited per IP (sliding-window). This reduces application-layer abuse but is not a substitute for network-level DDoS protection — operators exposed to volumetric attacks should place a CDN/WAF in front of their deployment.
  • Malicious destination filtering: known phishing/malware domains and executable file extensions are rejected at link-creation time.

6. Your Rights & Data Removal

Under GDPR and KVKK (Law No. 6698) you may request access to, correction of, or erasure of your account data by contacting the instance operator above. Deleting an account removes its workspace and every link, domain, and click record that belongs to it.
