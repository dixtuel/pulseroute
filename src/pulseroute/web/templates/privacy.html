Privacy Policy & KVKK / GDPR Notice

TELEMETRY COMPLIANCE STANDARD • 2026

1. Data Privacy Principles

PulseRoute is engineered with Privacy-by-Design principles in accordance with EU General Data Protection Regulation (GDPR) and Turkey Personal Data Protection Law (KVKK No. 6698).

2. IP Address Anonymization

Raw visitor IP addresses are never committed to permanent storage. All incoming network addresses are masked in volatile memory by truncating the final octet (IPv4 /24 mask) or prefixing (IPv6 /48 mask).

3. Cookieless Tracking

The link dispatch engine operates completely without persistent tracking cookies. Telemetry is derived strictly from standard HTTP header fields.

4. Data Encryption & Security

Sensitive credentials, API keys, and webhook secrets are protected using AES-256 field encryption. Direct SQL parameters prevent injection attacks.
